# Algorithm Gate downloads

Latest original algorithm-maths edition — 16 November 2026.

Open **algorithm-gate-updated.html** on GitHub and choose **Download raw file** (the downward arrow above the code). Find the saved HTML in your laptop’s Downloads folder and double-click it to play offline.

For the source ZIP, download **download-backup.html**, open that saved page, and click **Download backup ZIP**. It contains this updated game, the untouched original attachment, the previous revision, and testing notes. The game itself needs only its HTML file.

This update lowers both heroes’ resting arms and branches below their jaws, and masks the arm, branch and attack trails behind the actual skull silhouettes. The grey arm line no longer crosses either face, including during damage flashes. The smooth branch attacks, recognisable skulls and existing Longreach behaviour are retained.

There are **28 additional timed beam gates**, bringing the total to **50 timed beams across ten chapters**, alongside the 11 existing timed blade crossings. Beams have dim inactive outlines, amber warnings and bright active columns. Permanent waiting stones and generous dark intervals support solo and co-op crossings; the covered gallery beam ends at its real ceiling.

Boss behaviour, arena geometry, movement physics, puzzle layouts, maths, upgrade balance and controls are unchanged by this revision. Shared lantern respawns are retained. **Slant Gate remains a separate, unchanged edition.**

Validation: 122 scripted timed-crossing cases, 20 layout checks, two consecutive-beam cases, 1,920 face render comparisons, 41 animation checks and 169 broader browser/engine checks pass. Lantern recovery and offline operation were also checked. These are automated simulations, scripted Chromium checks and screenshot inspections; no manual full-game playthrough was performed. See TESTING.md in the ZIP for details and limits.
